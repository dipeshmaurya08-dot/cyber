# CyberShield: Student Cybersecurity Awareness & Habit Assessment Platform

> **Project Topic:** Cybersecurity Awareness Survey Among Students  
> **Objective:** Assess cybersecurity habits; develop educational content or a simple awareness website.

---

## 🌟 Project Overview
**CyberShield** is an interactive, full-featured web application created to diagnose, evaluate, and elevate cybersecurity awareness among college and university students.

In modern university environments, students are frequent targets of sophisticated cyber threats including:
- **Academic Phishing & Fake Exam Notifications**
- **Advance-Fee Fraud & Fake Job / Internship Stipend Scams**
- **Unsecured Campus / Hostel Wi-Fi Eavesdropping**
- **Credential Stuffing due to Password Reuse**
- **Infostealers distributed via Pirated Software & Modded APKs**

This platform serves both as an **empirical research instrument** (capturing and analyzing student security behaviors) and an **interactive educational portal** (empowering students with defensive habits and verification tools).

---

## 🚀 Key Modules & Capabilities

### 1. 📋 Student Cybersecurity Habit Survey
- **12 Comprehensive Questions** across 6 critical domains:
  1. *Password Hygiene & Two-Factor Authentication (2FA)*
  2. *Phishing & Social Engineering Resistance*
  3. *Public / Campus Wi-Fi & Network Security*
  4. *Device Patching & Software Piracy Awareness*
  5. *Social Media Privacy & OSINT Oversharing*
  6. *Academic Data Backup & Incident Response Readiness*
- **Real-Time Scoring & Diagnostic Gauge**:
  - Score Calculation (0 – 100)
  - Risk Classification: **Cyber Guardian** (Low Risk), **Cautious Surfer** (Moderate Risk), **Cyber Vulnerable Student** (High Risk)
  - Domain-by-Domain breakdown with animated progress bars
  - Tailored action items and corrective advice for every submitted answer.

### 2. 🎓 Downloadable Student Cyber Hygiene Certificate
- Personalized completion certificate with:
  - Student Name, Academic Year, and Branch/Department
  - Verified Cyber Hygiene Score & Rating
  - Official Certificate Verification Token
  - Built-in **Print / Save as PDF** styling.

### 3. 📊 Live Survey Research & Analytics Dashboard
- Built specifically for academic presentations and statistical research:
  - **Radar Chart**: Domain-by-domain proficiency analysis
  - **Doughnut Chart**: Student body risk categorization
  - **Bar Chart**: Cyber awareness scores across academic progression (1st Year to 4th Year)
  - **Batch Data Generation**: "Add 20 Student Samples" simulation button for live demos
  - **Export Dataset to CSV**: Download the entire surveyed cohort in Excel/CSV format for academic reports!

### 4. 🕵️ "Spot the Phish" Interactive Simulator
- Hands-on scenarios replicating actual student-targeted attacks:
  - Fake Semester Exam Hall Ticket withhold notice
  - Authentic Google Security Sign-in alert
  - High-Paying Work-From-Hostel Internship Scam
  - Banking KYC APK download SMS trap
- Real-time clue inspection, red flag breakdowns, and performance badges.

### 5. 🔐 Password Strength & Entropy Analyzer
- Client-side password entropy meter (safe & private — no data ever leaves the browser).
- Estimates real-world brute-force crack time.
- Identifies dictionary words, repetitions, and common keyboard patterns.
- Built-in **Secure Password Generator** with customizable length and one-click copy.

### 6. 📚 Educational Knowledge Hub
- Filterable learning modules covering Do's & Don'ts for campus life:
  - Module 1: Phishing & Scholarship Frauds
  - Module 2: The Fortress Strategy (Password Managers & 2FA)
  - Module 3: Campus Wi-Fi Safety & VPN Hygiene
  - Module 4: Piracy, Modded APKs & Infostealers
  - Module 5: Social Media Privacy & OSINT Risks
  - Module 6: 3-2-1 Backup Strategy for Capstones & Assignments

### 7. 🚨 Student Emergency & Incident Response Center
- Immediate action steps for financial fraud or account hijacking.
- **National Cyber Crime Helpline (India): 1930**
- Direct integration to **cybercrime.gov.in**
- College IT Cell escalation guidance.

## 💻 Tech Stack & Architecture
- **Frontend Core:** Semantic HTML5, CSS3, Modern ES6+ JavaScript
- **Styling:** Tailwind CSS + Custom Cyberpunk / High-Tech Glassmorphic CSS (`css/style.css`)
- **Data Visualization:** Chart.js 4.x
- **Icons:** Font Awesome 6.5
- **Animations:** Custom CSS Keyframes + Canvas Confetti
- **Storage:** LocalStorage API (zero external database setup required, runs completely offline or on any browser)
